# Historical script archive

These scripts were moved from the top-level `scripts/` directory during the
2026-07 cleanup.  They remain in Git because they underpin archived results,
but they are intentionally outside the maintained execution surface.

For new work use the files in `../` and the operational documents under
`../../docs/`.  Do not repair or extend an archived script as a shortcut:
port the relevant idea into a maintained runner and document the change.
