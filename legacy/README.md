# Legacy Research Archive

This directory preserves superseded reports, historical experiment notes,
and the previous manuscript package. These files are retained for provenance;
they are not the current scientific source of truth.

Current entry points are in the repository root:

- [Results-heavy working manuscript](../WORKING_DRAFT_ALL_RESULTS_2026_07_20.md)
- [Scientific synthesis](../HIP_GAD_SELLA_SYNTHESIS_2026_07_17.md)
- [Theory and implementation audit](../HIP_GAD_SELLA_THEORY_AUDIT_2026_07_17.md)
- [Cross-benchmark result ledger](../BENCHMARK_RESULTS_2026_07_16.md)
- [Research plan](../RESEARCH_PLAN_GAD_VS_SELLA.md)

Archive layout:

- `reports/`: dated TeX/PDF reports, LaTeX build outputs, original
  `paper.pdf`, and their historical figure bundles.
- `notes/`: superseded experiment logs, status documents, handoffs, and
  finding notes.
- `gad-paper/`: the previous self-contained manuscript package extracted in
  June 2026.

Historical files may contain claims that were later corrected, including the
noise-unit labels, mass-dynamics interpretation, DFTB0 IRC semantics, and
the frequency of unintended HIP saddles. Use the current working manuscript
for any new writing.
